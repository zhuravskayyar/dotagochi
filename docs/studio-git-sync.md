# Git-синхронізація в Animation Studio

У блоці **КОМАНДНА СИНХРОНІЗАЦІЯ** є дві кнопки.

## Вхід через GitHub

Перед першим push натисніть **Увійти через GitHub**:

1. Studio автоматично перевірить або встановить офіційний GitHub CLI.
2. У браузері відкриється `github.com/login/device`.
3. Введіть одноразовий код, показаний у Studio, та підтвердьте доступ.
4. Studio отримає ім'я, login, аватар і email автора commit. Якщо email
   прихований у GitHub, використовується GitHub `noreply`-адреса.
5. GitHub CLI налаштує Git credential helper, а ім'я й email збережуться
   локально в `.git/config`.

OAuth-токен не передається у frontend, не записується в `localStorage`, `.env`
або файли репозиторію. GitHub CLI зберігає сесію в системному сховищі
облікових даних, якщо воно доступне, і повторно використовує її після
перезапуску Studio.

## Зберегти й відправити

Кнопка:

1. Імпортує вибране idle-відео, якщо воно ще не було імпортоване.
2. Оновлює спільний каталог анімацій.
3. Додає в commit лише папку поточного героя та `hero-animations.json`.
4. Виконує push у `origin/main`.

Якщо в Git index уже додані сторонні файли, операція зупиниться та покаже їхній
список. Це захищає незавершений код від випадкового commit.

## Отримати зміни

Кнопка виконує `git pull --ff-only origin main`. Pull дозволений лише у гілці
`main` і лише коли робоча тека чиста. Локальні незбережені файли не
перезаписуються.

## Автоматичне отримання при запуску

`start-app.ps1` на Windows і `start-app.sh` на Linux перевіряють `origin/main`
перед запуском. Якщо є локальні зміни або GitHub тимчасово недоступний,
лаунчер залишає поточну версію та продовжує запуск.

Для push використовується GitHub-акаунт, підключений у Studio.
